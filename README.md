# QuickCommands

Fabric mod for Minecraft 26.3 with short commands:

- `/c`, `/s`, `/sp`, `/a` - set creative, survival, spectator, adventure (yourself, or `/s <players>`)
- `/heal [players] [alsoFeed]`
- `/feed [players]`
- `/killall [shouldAlsoKillPlayers]`

Build with `./gradlew build`; the jar ends up in `build/libs/`.
